# v0.16.321

The repository workflows now use the reviewed Dependabot major updates for `actions/checkout@v7`, `actions/setup-python@v6`, `astral-sh/setup-uv@v7`, `actions/upload-artifact@v7`, and `actions/download-artifact@v8`.

## Changed

- CI, Embodied CI, dependency-upgrade verification, auto-reproduction, and tag Release jobs now share the updated action majors without changing their job commands or publication order.
- Fresh final-SHA CI and release-preflight runs remain required before this maintenance release is treated as published.

## Trust Boundaries

This release does not create, install, or promote a candidate adapter package. It does not prove metadata validation, online smoke, browser workflow success, or live LLM availability. Candidate package promotion remains blocked by the real strict live-LLM preflight when that provider is unavailable.
