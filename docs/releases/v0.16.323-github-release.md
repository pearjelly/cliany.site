# v0.16.323

## Changed

- Strict release readiness now requires the reviewed `actions/setup-python@v7` major in both master CI and tag Release Preflight.
- This hardens the merged Dependabot action upgrade without changing CLI, adapter, SDK, HTTP API, workflow jobs, or release ordering.
- Fresh final-SHA GitHub CI and Embodied CI remain required before the tag is created.

## Compatibility

- No runtime or adapter contract changes.
- The live candidate promotion gate remains explicit: a retryable `E_LLM_UNAVAILABLE` / `llm_live_preflight_not_ready` does not create adapter packages or online-smoke evidence.

## Trust Boundaries

- Passing workflow and release gates proves repository publication readiness only; it does not prove browser, live LLM, adapter-package, or third-party workflow success.
