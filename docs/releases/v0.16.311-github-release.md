# v0.16.311

`doctor --json` now keeps local setup evidence independent from a failed live provider check.

## What Changed

- Added `capabilities.generate_adapters.local_blockers`.
- `local_ready` now ignores `llm_live`, so a provider outage no longer makes healthy local prerequisites look broken.
- Overall `ready` and `ready_for_live_explore` remain false on a failed live preflight, while `live_blockers` and `next_step` retain the provider blocker and strict retry command.

## Trust Boundaries

This is diagnostic separation only. The latest real preflight remained retryably unavailable; this release does not claim live LLM, candidate package, metadata validation, online smoke, browser replay, or third-party workflow success.
