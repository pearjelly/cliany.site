# v0.16.335

## Added

- Candidate issue audit preserves a GitHub rate-limit retry hint when the remote error provides `Retry-After` seconds or a rate-limit reset timestamp.
- Remote-read failures remain retryable `E_GITHUB_UNAVAILABLE`; the audit never synthesizes `missing` state or enters `--apply` before issue state is readable.

## Compatibility

- Issue creation, rewrite confirmation, candidate status semantics, CLI, adapter commands, SDK, HTTP API, and release ordering are unchanged.
