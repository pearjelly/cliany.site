# v0.16.341

## Fixed

- The public site and documentation no longer request Google Fonts at runtime. Explicit system UI, serif, and monospace stacks keep pages readable when a third-party font service is unavailable.
- Removing those external font requests prevents the previous browser console error from a failed Google Fonts connection and removes that dependency from the first render.

## Compatibility

- Typography retains separate heading, body, and code font categories through local fallback stacks. No CLI, adapter, SDK, HTTP API, or workflow behavior changes.

## Trust Boundaries

- A clean website console only proves the inspected static pages did not request the removed font service; it is not evidence of Chrome, live LLM, candidate adapter, or third-party workflow readiness.
- Candidate adapter package promotion remains gated on a real successful live LLM provider preflight.
