# v0.16.292

First-run users now receive a concrete active-demo path directly from `cliany-site doctor`.

## What Changed

- When the published active demo target is absent, the human `doctor` output prints fixed-SHA installation, `verify --strict`, and the read-only demo command in their safe order.
- The advice remains copyable guidance only: doctor does not download, install, execute, or overwrite an adapter.
- When an active demo target is already installed or merely occupied, the human path still begins with strict verification before any read-only command.

## Compatibility

`demo_adapter_quickstart`, its compatibility `commands`, and JSON `recommended_commands` are unchanged. The fallback without a usable active demo remains `cliany-site cases`.

## Trust Boundaries

This release does not open a browser, run a live LLM call, generate, download, install, or execute an adapter, or claim a candidate or third-party workflow succeeded online.

## Verification

Doctor human-output regression tests, full offline tests, package build and Twine validation, required CI, GitHub Release, PyPI, Vercel production deployment, website browser inspection, and strict publication audit are required before release completion.
