# v0.16.303

SDK and HTTP callers now receive actionable adapter diagnostics before a browser session is started.

## What Changed

- `ClanySite.execute()` now validates `domain` as a single safe adapter directory name and applies the runtime loader's static contract before browser startup: metadata must be a JSON object, `commands.py` must be a regular file, and it must export a `click.Group` named `cli`.
- A current-schema installed adapter that fails those checks returns `E_VERIFY_STATIC` with `domain`, `verdict`, and `reason`, plus the compatible `cliany-site verify <domain> --strict --json` repair path.
- `POST /execute` maps those static adapter failures to HTTP `422`, preserving `404` for missing adapters and `400` for invalid requests.
- The SDK/API now applies the strict verify banned-pattern and UTF-8 read checks before importing `commands.py`, returning `security_issue` instead of executing a rejected or unreadable module during preflight.
- Non-object metadata is handled as a bounded parse error or skipped by discovery instead of causing an unsafe `.get()` assumption.

## Compatibility

Working adapters keep their existing SDK/API execution behavior. The new preflight applies only to installed current-schema adapters that cannot satisfy the loader contract; legacy metadata, missing adapters, browser setup, and action replay semantics remain unchanged.

## Trust Boundaries

The preflight may load an installed, trusted `commands.py` to verify the `click.Group` contract, but it does not establish Chrome/CDP availability, session validity, action success, GitHub Release, PyPI, Vercel deployment, a candidate adapter package, metadata validation, online smoke, a live LLM provider, or a third-party workflow. Candidate promotion remains pending on its required evidence.

## Verification

Focused CLI, loader, metadata, SDK/API, and documentation regressions; full offline tests; package build and Twine validation; required CI; GitHub Release; PyPI; Vercel production deployment; website browser inspection; and strict publication audit are required before release completion.
