# v0.16.387

## First Results Need Real Fields

The read-only `demo` now checks every returned row against its case's declared nonblank text fields: Jira key/summary, Confluence id/title and Jenkins name/url. Missing, whitespace-only or non-text values fail with existing `E_EMPTY_RESULT`, `stage=oracle` and 1-based `error.details.field_invalid_rows`. The new diagnostic reports names and positions without copying bad values. A nonempty object alone is no longer sufficient for first-result success.

Successful result payloads and optional fields are unchanged. Fixed public adapter URLs/hashes, strict verification, no overwrite, stop-on-failure, no retries and the existing 90-second child budget remain intact. No installed generated adapter is rewritten. The evidence recorder shares the runtime row oracle; the standalone catalog validates the same declared contract and has bootstrap/parity regressions. Two hand-authored examples now match the maintained packages' result paths and remain marked synthetic.
