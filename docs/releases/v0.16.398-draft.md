## 用户价值

按名称输入时，初始化期间的临时同名输入框不再导致过早失败。文档初始化后重新观察可访问性树；目标变为唯一时正常输入，仍有同分目标则返回 `target_ambiguous`，不输入、不提交。

探索同一轮连续点击同一个实测跨页链接时，执行和录制前要求修正。点击一次后重新观察目标页，不把上一页的入口误作仍可操作的控件。

## 案例库映射

`cases/README.md`、`cases/manifest.json` 和四个 active 固定归档不变，`search-extraction-gap` 保持已知缺口，不晋级候选。真实探索前运行 `doctor --llm-live --require-capability generate_adapters --json`；`llm_live_preflight_not_ready` 或上游不可用时保留证据并停止。

独立试用固定 0.16.387，0/2 人。A/B、首次失败、帮助和重试分别记录，维护者复测不计入。

## 风险与兼容性

[证据](../user-evidence/2026-11-12-settled-input-target.md)区分临时重复、持久重复和未复现的历史文档失败。保留原 10 秒只读预算、显式 ref 和验证页检查，不新增重试或 CSS 兜底，不改生成文件。不承诺处理任意 DOMContentLoaded 后的异步渲染，也不推断 #124 根因。

[首个候选包失败](../user-evidence/2026-11-12-duplicate-navigation-plan.md)保留 2/3 工作流及 6/9 计划回放。修复沿用同一个有限规划修正，不跨观察批次去重，不修改现有回放。修订候选必须重新完成真实工作流门禁。
