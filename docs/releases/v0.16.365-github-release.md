# v0.16.365

## Maintained ASF Confluence keyword search

The historical Confluence adapter treated `--query` as an exact title filter and returned no rows for `SPARK` / `release`. This release provides a separately maintained, read-only adapter that uses Confluence's public CQL search endpoint. An isolated package install passed strict verification, and the installed CLI returned five public pages for that query.

Install the reviewed archive with its pinned SHA-256:

```bash
cliany-site market install https://github.com/pearjelly/cliany.site/releases/download/v0.16.365/cwiki.apache.org-0.16.365.cliany-adapter.tar.gz --sha256 85ab3e918f32070fd69ae2947e69530b936a9d6655588d5153612d2686cac84f
cliany-site verify cwiki.apache.org --strict --json
cliany-site cwiki.apache.org search-pages --space SPARK --query release --limit 5 --json
```

The installer will not overwrite an existing adapter without an explicit `--force`. Review an install with `--dry-run --json` first. The original generated adapter is unchanged. The case remains marked degraded until the public Release asset passes an independent pinned-hash install and read-only replay audit; third-party site availability and result relevance can change.
