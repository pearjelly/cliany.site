# v0.16.375 发布草案

**目标版本：** `0.16.375`
**提交范围：** `v0.16.374..HEAD`（以最终 master 为准）
**状态：** 候选；2026-10-04 上海时间的 3 次发布配额已用完，不得在当日推送 tag。

## 用户价值

- 官网快速上手代码块的复制按钮不再覆盖命令；长命令在小屏和平板上可阅读，复制内容仍是可执行原命令。
- 手机端扩展特性网格不再产生隐式第二列、异常高度和整页横向滚动；长诊断字段名可换行。
- 官网贡献者、维护者及实验性 provider 的高级说明默认折叠，保留内容与键盘访问，同时缩短到反馈入口的滚动距离。
- 桌面页眉给完整导航留出空间；视口不足时提前切换菜单，避免链接挤到品牌文字。

## 验证证据与边界

- [PR #57](https://github.com/pearjelly/cliany.site/pull/57) 和 [PR #58](https://github.com/pearjelly/cliany.site/pull/58) 均通过完整 CI，包括具身 Chromium。维护者在 320、390、768、1280px 浏览器视口检查布局；320px 英文特性区可见，页面无横向溢出。
- 本版只改官网呈现，不改变 CLI、adapter schema、案例库或发布包行为。Python 文档站候选适配器仍缺独立首次用户验收；[Issue #55](https://github.com/pearjelly/cliany.site/issues/55) 保持开放。

## 案例库映射

`cases/README.md` 与 `cases/manifest.json` 保留现有 active/candidate 状态，`search-extraction-gap` 不变。Python 文档站仍是 candidate，不因官网修复晋级；真实探索若返回 `llm_live_preflight_not_ready`，先记录阻塞，不把它当作成功证据。

## 风险与兼容性

本版不改 CLI 命令、JSON envelope 或 adapter 包格式。移动端布局已由维护者在多个视口验证，但独立用户首次完成浏览器工作流的证据仍缺失。合成 OS `HOME` 下的 macOS Chrome 导航超时仍由 Issue #53 跟踪，本版不改浏览器启动环境。

## 发版前验证

1. 配额重置后，在最终 master 更新版本、CHANGELOG、官网基线与相关断言；验证本说明仍覆盖 `v0.16.374..HEAD` 的全部用户可见变化。
2. 在最终 master SHA 运行完整离线测试、具身 Chromium、Ruff、Mypy、`uv lock --check`、官网脚本、案例严格校验、wheel/sdist 构建与 Twine 检查；确认普通和 Embodied CI 均通过。
3. 先运行 `uv run python scripts/check_github_release_cap.py --strict --json`，再运行 `uv run python scripts/release_readiness.py --strict --target-version 0.16.375 --remote --remote-name origin`。仅在两者都通过时创建本地 tag，以 `--release-tag v0.16.375` 严格复核后推送。

## 发版步骤

1. 等待 GitHub Release 和 PyPI 精确版本公开，核对本版审阅过的 Release notes。
2. 在 `site/` 执行 `vercel link --yes --project cliany.site` 和 `vercel --prod --yes`，检查生产别名、首页与文档页版本。
3. 从干净 master 运行 `scripts/check_release_publication.py --strict --remote --distribution --json`，独立用户试用仍由 Issue #55 验收。
