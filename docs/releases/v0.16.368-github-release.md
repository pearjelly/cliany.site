# v0.16.368

## ASF Jenkins Demo Is Now Active

The maintained, read-only Jenkins job-list case is now an active first-run demo. The exact [v0.16.367 public archive](https://github.com/pearjelly/cliany.site/releases/tag/v0.16.367) passed an independent SHA-256 download, fresh-HOME installation, strict verification, and online query with the published PyPI CLI. It returned five of 106 top-level entries. The `demo` command installed and verified the package in another empty HOME, returned five rows, and reused the installation on a second run.

```bash
cliany-site demo --case-id apache-jenkins-jobs --json
```

The [public package audit](https://github.com/pearjelly/cliany.site/blob/master/docs/user-evidence/2026-10-02-jenkins-public-package-audit.md) records the exact archive hash and limits. Existing adapters are not overwritten automatically; review an occupied installation with `cliany-site verify builds.apache.org --strict --json`. The historical v0.14.1 archive is still unsuitable. ASF availability and job totals may change.
