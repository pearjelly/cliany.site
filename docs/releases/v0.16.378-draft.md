- CLI 使用单调的每调用计时上下文；成功、渲染错误和嵌套调用有明确的取样边界，不再把未初始化的计时误作 0 毫秒完成。
- 可选 `meta.duration_measured` 标记区分实测值和不可用占位，旧信封版本、其他字段及 SDK/HTTP 顶层格式不变。新生成模板取父调用快照，已有生成文件不改写。
- 文档安装、配置与快速上手锚点保留原生鼠标、键盘、刷新和历史导航，标题显示在固定页头下方。

## 风险与兼容性

只在 `duration_measured=true` 时使用时间值；亚毫秒真实调用允许取整为 0。标记为 false 或不存在时不得推断命令速度。根入口到元数据构造的时段不等于整个进程或每个 HTTP 请求的总时间；历史 adapter 的手工元数据可能需要重新生成才能取得父快照。

本轮不要求新模型探索或案例晋级。未来若真实探索的严格预检返回 `llm_live_preflight_not_ready`，先恢复可用性再继续，不把未启动的试验算作成功。旧包复测和绿色 CI 不替代独立首次使用或第三方持续可用性。
