# v0.16.313

v0.16.313 restores the production homepage after release-time browser inspection found that an apostrophe in the English maintainer translation made `site/script.js` invalid JavaScript.

## Fixed

- Use a quote-safe delimiter for the long English maintainer translation so `manifest's` cannot terminate the JavaScript string.
- Lock the executable translation form in site regression coverage.
- Require `node --check site/script.js` and a clean production browser console before closing publication.
