# v0.16.372

## Correct Structured Result Fields

When a result row has no matching link or snippet, structured extraction now leaves that field blank. It no longer borrows a URL from a neighboring row or substitutes the entire row's text for a missing child field. The existing extraction-quality gate reports the incomplete row instead of allowing misleading data to look successful.

A Chromium regression reproduced the cross-row URL error before the fix and passed afterward. This release does not include the draft generated-workflow reliability study in [PR #47](https://github.com/pearjelly/cliany.site/pull/47); its latest controlled 30-trial result remains below the target. Independent first-use validation is still open in [Issue #33](https://github.com/pearjelly/cliany.site/issues/33).
