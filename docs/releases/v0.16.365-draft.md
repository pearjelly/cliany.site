# v0.16.365 发布草案

**目标版本：** `0.16.365`
**提交范围：** `v0.16.364..HEAD`

## 用户价值

- 提供维护中的 ASF Confluence 只读关键词搜索 adapter 包。历史 v0.14.1 包将 `--query` 用作精确标题过滤，`SPARK` / `release` 返回空列表；新包使用公开 CQL 搜索接口，在隔离安装中返回 5 条页面。
- 案例目录、中英 README 和官网文档提供固定 SHA-256 安装路径。已有同名 adapter 不自动覆盖；用户可先 dry-run，确认后再显式选择替换。

## 当前证据

- 2026-10-01 的真实 `doctor --llm-live --require-capability generate_adapters --json` 预检通过；这只证明上游可用，不是新站点探索成功。
- 已冻结的 `cwiki.apache.org-0.16.365.cliany-adapter.tar.gz` SHA-256 为 `85ab3e918f32070fd69ae2947e69530b936a9d6655588d5153612d2686cac84f`。临时 HOME 中的 dry-run、安装和 `verify --strict` 均通过；从安装后的 CLI 执行 `search-pages --space SPARK --query release --limit 5 --json` 返回 5 条，首条为 `Preparing Spark Releases`。
- [CQL 实测与边界](../user-evidence/2026-09-28-confluence-cql-probe.md)记录了只读请求与结果。发布后仍需从 GitHub Release 下载相同 SHA-256 包，在新的隔离 HOME 中重新安装与回放。

## 案例库映射

- `cases/manifest.json` 的 Confluence 安装命令指向本版固定哈希资产，`cases/README.md` 说明它仍为 degraded；公开包独立验收前不晋级 active。
- `apache-jira-issues` 和 `suitecrm-accounts` 保持 active，`apache-jenkins-jobs` 保持 degraded。PyPI、npm 和 crates.io 搜索仍为 candidate；`search-extraction-gap` 仍为 known-gap。
- 候选晋级仍须遵守真实预检门禁；出现 `llm_live_preflight_not_ready` 时不得声称真实模型探索完成。

## 风险与兼容性

- Confluence 是第三方服务，在线结果和可达性可能变化；当前实测不证明每条结果都与关键词同等相关。
- 发布工作流自动生成 Python wheel/sdist；维护包由已冻结的本地字节单独上传 GitHub Release，不重新生成以免时间戳改变 SHA-256。上传或公网哈希核对失败时保留 degraded，停止晋级。
- 不编辑历史自动生成文件，也不替换用户已安装的 adapter。

## 发版前验证

- 复核远端 master、当天 tag 数、GitHub Release、PyPI、官网与案例证据；运行完整离线测试、Ruff、Mypy、案例校验、网站脚本、wheel/sdist 与 Twine 检查。
- 最终 master SHA 的普通 CI 和真实浏览器 CI 均须成功；tag 前严格 target readiness 与本地 tagged readiness 均须通过。

## 发版步骤

1. 合并并验证最终 master 后创建本地 `v0.16.365` tag；严格 tagged readiness 通过后才推送。
2. 等 GitHub Release 与 PyPI 精确版本发布，上传已冻结的 Confluence 包，校验远端资产哈希；从公网资产做隔离安装、严格校验和只读回放。
3. 从 `site/` 部署 Vercel 生产，核对 `www.cliany.site` 首页、文档页和生产别名；最后执行严格远端分发审计。
