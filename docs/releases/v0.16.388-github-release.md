# v0.16.388

## Readiness Probes Share The Existing Budget

The existing ten-second list-readiness budget now covers the awaited browser probe, not just time between polls. A response arriving after the deadline cannot become a stable success. Nonnegative integer counts and boolean loading flags are required; valid JSON-encoded probe states still work. External cancellation continues to propagate.

A newly captured Python Docs failure showed the probe calling `querySelector` on a missing document body. Missing scope now means still loading within that same budget, not a JavaScript exception or an empty success. A body that never appears still fails. This fixes the captured condition, not every possible public-site or browser failure.

Legacy atom extraction and action replay distinguish fixed `settle_probe_failed`, `settle_probe_invalid` and `settle_probe_timeout` categories from `list_unsettled`, without including probe values or exception bodies. Error codes, successful payloads, semantic target identity, empty-result policy, pinned archives, generated adapter files and the 100-row cap remain unchanged. Semantic target resolution uses the corrected shared budget but retains its prior coarser error contract. There are no action, navigation or model retries.

## Evidence And Limits

The [dated evidence](https://github.com/pearjelly/cliany.site/blob/master/docs/user-evidence/2026-10-17-list-settle-budget.md) retains the original published-package failure, a separately observed JavaScript probe exception, ten initial failing regression checks, native-test wiring failures and later checks. The earlier failure's precise subcause is not recoverable; a later pass is not a rescore or a claim that every public-site problem was repaired. Controlled real-CDP slow probes and normal public workflow results are separate evidence.

This is a cooperative readiness budget, not a complete-command deadline, a guarantee against a blocked event loop, or continuing browser/provider availability. No CSS locator fallback, generated-file rewrite, new live model exploration or case promotion is introduced. Independent first-use reports remain **0/2**; the [fixed trial](https://github.com/pearjelly/cliany.site/blob/v0.16.387/docs/first-use-trial.md) stays at already published 0.16.387, preserving original versions, failures and assistance timing. Final-source/master, publication, official-package acceptance and the strict remote distribution audit require their own receipts.
