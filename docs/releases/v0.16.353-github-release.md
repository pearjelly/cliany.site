# v0.16.353

## What Changed

- Added synchronous Python SDK `save_session(domain, cdp_url=..., headless=...)` for callers that do not manage an async event loop.
- The helper delegates to `ClanySite.save_session(domain)`, preserving the same optional CDP/headless configuration and host validation before Chrome or session persistence begins.

## Compatibility

Existing asynchronous SDK calls are unchanged. The synchronous helper accepts normal hosts, host:port values, and bracketed IPv6 hosts; invalid session identifiers return the same local `E_INVALID_PARAM` envelope.

## Trust Boundaries

This is a local SDK convenience API. It does not establish Chrome availability, live LLM success, candidate adapter package availability, metadata validation, online smoke, or third-party workflow success.
