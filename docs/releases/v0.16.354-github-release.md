# v0.16.354

Fixed live LLM preflight for OpenAI-compatible providers that enforce JSON mode. The health-check prompt now requests a JSON object, matching the client's response format instead of requesting plain-text OK.

A regression test exercises the real ChatOpenAI request serialization against a simulated strict HTTP endpoint. The existing provider error handling is unchanged.

The configured live upstream still failed its TLS connection on September 22. This fix does not claim live LLM availability or promote candidate adapters.
