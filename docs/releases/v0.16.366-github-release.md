# v0.16.366

## Confluence Search Joins Active Demos

The maintained ASF Confluence keyword-search adapter is now an active read-only case. Its published v0.16.365 archive passed an independent SHA-256-pinned install, strict verification and nonempty public-page query. A fresh isolated first run of the new `demo` path installed the archive and returned six pages; a second run verified and reused it without overwriting the adapter.

Try the one-command path:

```bash
cliany-site demo --case-id apache-confluence-search --json
```

`demo` now reports Confluence page IDs and titles in human output and names the correct domain in query failure hints. The offline case example reflects the maintained adapter's result shape. The historical v0.14.1 exact-title adapter remains unsuitable; an existing installation is never overwritten automatically. Apache Jenkins remains degraded, and third-party search availability and relevance can change. See the [public package audit](https://github.com/pearjelly/cliany.site/blob/master/docs/user-evidence/2026-10-01-confluence-public-package-audit.md).
