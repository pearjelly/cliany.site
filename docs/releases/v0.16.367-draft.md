# v0.16.367 发布草案

**目标版本：** `0.16.367`
**提交范围：** `v0.16.366..HEAD`

## 用户价值

- 提供受维护的 ASF Jenkins 公开顶层 job 列表包。历史 v0.14.1 包缺少 schema v3 必填元数据；新包使用只读 Jenkins JSON API，区分返回行数与总行数，结果链接只接受 Apache Jenkins HTTPS 域名。
- 在隔离环境中完成固定哈希 dry-run、安装、严格校验和只读查询。案例仍为 degraded，直到同一归档的公网资产通过独立安装与回放验收；不修改用户已有或历史自动生成 adapter。

## 当前证据

- 冻结归档 `builds.apache.org-0.16.367.cliany-adapter.tar.gz` SHA-256：`10ac9f4dc1ce2b4cc364d9fe9517e1ecabd50743885f404040abf8fc248ef18b`。隔离 HOME 中的已安装命令返回 `count=5`、`total=106`，首条 job URL 返回 HTTP 200；详见[候选证据](../user-evidence/2026-09-28-jenkins-curated-candidate.md)。
- 增加受维护 adapter 的离线 CI job；PR job 设置 `CLIANY_QA_OFFLINE=1`，不使用真实 LLM 密钥。真实模型预检不是 Jenkins 只读 API 包的运行前提。

## 案例库映射

- `cases/manifest.json` 指向本版固定哈希 Jenkins 包，但保持 degraded；`cases/README.md` 明确公开包独立验收仍待完成。`apache-confluence-search`、Jira 与 SuiteCRM 保持 active。
- PyPI、npm 和 crates.io 搜索仍为 candidate；`search-extraction-gap` 保持 known-gap。candidate 的真实模型预检若出现 `llm_live_preflight_not_ready`，不得推进 explore 或伪称已有可用包。

## 风险与兼容性

- ASF Jenkins 是第三方服务，job 名称、数量和可达性会变化。本地查询不证明所有条目都可执行，也不证明发布后的公网资产可安装。
- 发布工作流只自动上传 Python wheel/sdist；冻结的 Jenkins 归档须原字节单独上传 GitHub Release。若上传或远端哈希核对失败，停止晋级并修正文档。

## 发版前验证

- 检查远端 master、当天 tag 数、Release/PyPI/官网基线；运行完整测试、Ruff、Mypy、案例严格校验、网站脚本、wheel/sdist 与 Twine 检查。
- 最终 master SHA 的普通 CI 和真实浏览器 CI 均须成功；tag 前严格 target 和本地 tagged readiness 均须通过。

## 发版步骤

1. 合并并验证最终 master 后创建本地 `v0.16.367` tag，通过严格 tagged readiness 再推送。
2. 等 GitHub Release 与 PyPI 发布精确版本，上传冻结的 Jenkins 包并核对公网 SHA-256；从公开 URL 做全新隔离安装、严格校验和只读回放。
3. 从 `site/` 部署 Vercel 生产，核对 `www.cliany.site` 首页、文档和别名，最后执行严格远端分发审计。
