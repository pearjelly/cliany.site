# v0.16.361

## Candidate Next Step Is Now Accurate

The PyPI search adapter is already available as a public, SHA-256-verified GitHub Release asset. Its HTTPS installation and strict verification passed in fresh user directories. `cliany-site cases` now records those package and metadata steps as complete and points contributors to the remaining read-only online search check. The case stays **candidate**: PyPI's `Client Challenge` has prevented a reliable normal search result, and this release does not bypass it.

## Release Audit Fix

The remote publication audit now handles annotated Git tags correctly by comparing their peeled commit IDs. A successfully published release no longer appears to have a missing tag merely because the tag has an annotation. Both lightweight and annotated tags are covered by tests.

## Verification And Limits

The public adapter asset digest and fresh-HOME installation evidence are recorded in `docs/user-evidence/2026-09-23-pypi-package-smoke.md`. Package verification does not establish that PyPI's browser search is available. Jev remains opt-in and read-only; its live TypeSafe accuracy has not been measured.
