# v0.16.291

Server and Docker users now get copyable `explore` commands that match the actual CLI option hierarchy.

## What Changed

- `--headless` and `--cdp-url` are documented as root options before `explore`, instead of unsupported `explore` subcommand flags.
- The docs now separate two browser-management paths: let cliany-site launch headless Chrome, or connect to an already-running remote CDP browser.
- The website's `explore` options list now reflects the real command help, including `--force` and `--record/--no-record`.

## Compatibility

This is a documentation correction. Existing CLI behavior, JSON envelopes, CDP connection rules, and adapter schemas are unchanged.

## Trust Boundaries

This release does not open a browser, run a live LLM call, generate or install an adapter, or claim a candidate or third-party workflow succeeded online.

## Verification

CLI help-contract checks, website/documentation regression tests, the full offline suite, package build and Twine validation, required CI, GitHub Release, PyPI, Vercel production deployment, website browser inspection, and strict publication audit are required before release completion.
