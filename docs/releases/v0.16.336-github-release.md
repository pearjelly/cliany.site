# v0.16.336

## Fixed

- Ordinary `cliany-site doctor --json` now returns an existing stable error code such as `E_CDP_UNAVAILABLE` when a hard environment check fails, instead of collapsing the failure into `E_UNKNOWN`.
- The complete doctor `checks` and `summary` remain available in `error.details` for human diagnosis and automation.

## Compatibility

- Successful checks, warning-only checks, the strict capability gate, CLI, adapter commands, SDK, HTTP API, and release ordering are unchanged.

## Trust Boundaries

- This release contains no candidate adapter package, live LLM success, online smoke result, or third-party workflow claim.
