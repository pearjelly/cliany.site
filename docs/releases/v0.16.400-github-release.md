# v0.16.400

Generated browser searches can ground an unlabeled result list in the main landmark without confusing it with pagination or nested metadata. A single-list workflow can opt into an independently confirmed zero-match message and an output limit. The runtime checks the active query, and a returned prefix does not hide errors in the rows that were inspected.

Marketplace preview and installation now report missing generated runtime helpers before writing adapter files or replacing an installed adapter. The compatibility check does not execute archive code and does not replace strict verification or browser replay.

Named input now distinguishes an unfinished document from an initialized page with no matching field. It uses the same observation budget and never retries typing or submission. See the [controlled Chromium comparison](https://github.com/pearjelly/cliany.site/blob/master/docs/user-evidence/2026-11-12-missing-input-readiness.md).

During exploration, a single late result list can be observed again within the existing budget after a confirmed same-origin form transition. Extraction still needs a unique list on that result page; it does not resubmit the form or turn missing rows into a zero match.

Exploration also stops a second click planned from the old document after an observed same-tab cross-page link. It uses the existing one-plan correction to request a fresh observation. If the plan cannot be corrected, neither click is dispatched. See the [recorded failure and Chromium controls](https://github.com/pearjelly/cliany.site/issues/141).

Doctor shows the recovery action when a live probe fails without changing its request budget. For automation, read `openai_base_url.details.configured` instead of the removed raw address field. Addresses rejected by the local validator return `E_INVALID_PARAM` before any provider request.

See [semantic result targets](https://github.com/pearjelly/cliany.site/blob/master/docs/semantic-extract-targets.md) and the [retained compatibility failure](https://github.com/pearjelly/cliany.site/pull/135#issuecomment-6817535082). The crates.io archive remains a candidate pending public-package verification. The independent trial remains pinned to v0.16.387.
