# v0.16.371

## Marketplace JSON Compatibility

`cliany-site market ... --json` now includes `ok` with the same boolean value as the existing `success` field. The existing `success`, `data`, and `error` fields remain, including `error.fix` hints. This is an additive response change for scripts that use the CLI's `ok` convention.

## Chrome Startup Diagnostics

When an auto-launched Chrome process fails to make its CDP endpoint ready within the existing 20-second window, the timeout now includes bounded observations: elapsed time, process state, TCP port state, and whether the temporary profile was created. It does not expose Chrome stderr, URLs, page content, or profile paths. The wait duration and process cleanup are unchanged. This helps investigate [Issue #36](https://github.com/pearjelly/cliany.site/issues/36); it does not claim to fix intermittent startup failures.

The browser-generated command reliability study remains draft at 25/30 strict replays, below its 27/30 target. Two independent first-use trials are also still needed in [Issue #33](https://github.com/pearjelly/cliany.site/issues/33).
