# v0.16.390

## Preserve Input Through Document Initialization

Named browser input observes a delayed semantic target and document initialization within one existing ten-second preparation budget, then refreshes AX references before dispatching once. The captured site initializer previously reset an already typed query before submission. An interactive document with completed DOMContentLoaded is sufficient; slow images need not finish. A stalled or late initialization probe returns `E_PAGE_NOT_READY / document_not_ready` before input. Explicit refs remain single-snapshot, and equal-score refusal, challenge handling, cancellation and clear/Enter behavior retain their existing boundaries.

Semantic list/table/status extraction shares its existing ten-second budget across initial identity resolution, settling and recapture. Delayed observed regions can become ready; missing, ambiguous or late regions remain errors instead of becoming empty success. No guessed CSS fallback, action/navigation/model retry, generated-core rewrite, row-limit increase or case promotion is added.

## Evidence And Limits

The [dated evidence](https://github.com/pearjelly/cliany.site/blob/master/docs/user-evidence/2026-10-17-semantic-workflow-readiness.md) preserves the official v0.16.389 public study (1/3 complete workflows, 6/9 replays), first fixed-source study (1/3, 7/9), separate captured diagnostic failures and native red reproductions. A new clean-source strict live preflight and three fresh real generations passed; all nine changed-query replays matched independent completed pages, including three valid zero matches. Six positive outputs are ordered 100-row prefixes, not complete collections. Pre-version offline regression passed 3,734 tests and exact-head ordinary/Chromium CI. Final version/master and official installed-package/publication gates require their own receipts.

These are maintainer checks on one public site, not independent first use or a general reliability claim. Preparation budgets are cooperative, not whole-workflow deadlines, and arbitrary post-DOMContentLoaded SPA hydration is not established. Independent first-use reports remain **0/2**; the [fixed human trial](https://github.com/pearjelly/cliany.site/blob/v0.16.387/docs/first-use-trial.md) remains on published 0.16.387. Earlier failed attempts and assistance timing are never rescored.
