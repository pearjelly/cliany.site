# v0.16.374

## Try a Browser-Generated Read-Only Command

The [quickstart](https://github.com/pearjelly/cliany.site/blob/master/docs/quickstart-10min.md#可选试用浏览器生成的-python-文档候选命令) now gives a pinned install, strict verification, and replay path for the public Python documentation adapter. The website links the same trial and [independent feedback issue](https://github.com/pearjelly/cliany.site/issues/55). Running the existing adapter requires Chrome, but no LLM key.

List extraction now includes `row_limit=100` and `limit_reached` in the quality output for both the built-in browser command and generated adapters. `limit_reached=true` means the returned list hit the cap; it does not prove there are more rows or that all site matches were collected. Field quality may still be `ok`.

A maintainer reinstalled the [public adapter archive](https://github.com/pearjelly/cliany.site/releases/download/v0.16.373/docs.python.org-0.1.0.cliany-adapter.tar.gz), passed strict verification, and replayed `pathlib` with 100 rows and the independently observed first title/link. The adapter remains a candidate: independent first-user evidence is missing, and a synthetic-OS-`HOME` Chrome navigation failure on one macOS host remains under investigation. The existing archive is unchanged; no new adapter asset is part of this release.
