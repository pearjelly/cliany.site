# v0.16.400 发布草案

**目标版本：** `0.16.400`

**提交范围：** `v0.16.399..HEAD`，以最终 master 为准。

**状态：** 组合候选，尚未发布。CHANGELOG 的 2026-11-13 为上海时间最早拟定日期，不是发布收据；必须先完成并核对 v0.16.399 的三端发布。若日期、基线或最终提交变化，重新确认版本文案和受影响门禁。

## 用户价值

无标签的原生结果列表可依据主区域和直属标题链接定位，排除分页与嵌套统计。新生成的单列表搜索可选择验证明确零匹配，并在检查全部已提取行后限制返回前缀。安装预检会在写入前提示缺少的运行时功能，不执行包内代码。

## 案例库映射

crates.io 仍是 `candidate`：更新了可复核的命令和历史证据，不更改状态、公开来源或四个 active 固定包。用真实浏览器分别核对 `serde`、`tokio` 的前五条名称和链接，以及已观察到的明确零查询。Python Docs 的原公开固定包和独立用户试用 `0.16.387` 保持不变。

## 风险与兼容性

- [Issue #131](https://github.com/pearjelly/cliany.site/issues/131) 和 [PR #132](https://github.com/pearjelly/cliany.site/pull/132#issuecomment-6816703027) 保留列表未定位和明确零结果失败。缺失、加载中或有歧义的页面仍不算零匹配。
- [PR #134](https://github.com/pearjelly/cliany.site/pull/134#issuecomment-6817333134) 的私有生成和固定包各通过 5/5/0 真实对照；这不是组合候选或公开运行时的证明。`--limit` 不降低提取质量门禁，不代表全站完整收集。
- [PR #135](https://github.com/pearjelly/cliany.site/pull/135#issuecomment-6817535082) 保留 PyPI `0.16.398` 安装成功但严格校验失败的结果。旧 CLI 不因新源码修复而变得兼容；不改写已有生成文件。

## 发版前验证

- 核对版本、CHANGELOG、路线图、发布说明、官网首页和文档页。完成完整离线测试、静态与类型检查、案例及四个固定分发包检查、wheel/sdist 和 Twine；以最终提交的普通 CI 和 Chromium CI 为准。
- 安装组合候选 wheel。真实探索前执行 `doctor --llm-live --require-capability generate_adapters --json`；失败即保存结果并停止。分别验证 Python Docs 的查询和零结果，以及 crates.io 的 5/5/0、固定包新装与 SDK。基于独立普通页面核对返回值，保留失败，不用维护者测试替代独立用户验收。

## 发版步骤

- 仅在 v0.16.399 已发布且组合候选全部门禁通过后合并。最终 master 重新验证；创建和推送 tag 前在线分别核对上海当天 GitHub Release 实际发布时间，达到三次或结果不确定即停止。通过 tagged readiness 后才能推 tag。
- 核对 GitHub Release、PyPI 精确版本与实际安装包。按项目指引部署 Vercel `cliany.site`，检查首页、文档页和生产别名，最后运行严格远端分发审计。官网无 `/console` 路由。
- 仅在支持的公开 CLI 可核验之后考虑发布固定 crates.io 资产。用实际 PyPI CLI 与公开下载的同一包重新完成 SHA-256、新装、严格校验和只读三次重放；另作验收记录，未通过不晋级。
