## 用户价值

无标签的原生结果列表可依据主区域和直属标题链接定位，排除分页与嵌套统计。新生成的单列表搜索可选择验证明确零匹配，并在检查全部已提取行后限制返回前缀。安装预检会在写入前提示缺少的运行时功能，不执行包内代码。

按名称输入时，初始化未完成且输入框还未出现，等待预算耗尽后报页面未就绪；文档就绪却没有匹配仍报找不到元素。沿用原有预算和显式 ref 行为，不增加输入或提交次数。

探索提交表单并观察到同源页面切换后，单个列表如果还未出现，会在原有提取定位预算内重新观察。必须在同一结果页唯一定位才会抽取；不重提表单，不把缺失当零匹配。

从同一次观察规划了相邻点击、且第一项是实测同标签页跨页链接时，执行前要求重新规划；下一次点击须来自目标页的新观察。沿用一次规划修正预算，不能修正则不派发；同一链接重复点击保留原错误分类。

严格模型预检失败时，顶层提示显示已有的具体排查建议，不增加请求。诊断只报告是否配置了自定义服务地址；原有校验无法解析的地址在请求前返回 `E_INVALID_PARAM`。

## 发版前验证

- 核对版本、CHANGELOG、路线图、发布说明、官网首页和文档页。完成完整离线测试、静态与类型检查、案例及四个固定分发包检查、wheel/sdist 和 Twine；以最终提交的普通 CI 和 Chromium CI 为准。
- 用安装包核对有效 JSON、格式错误、连接中断、认证拒绝和无效地址。保留失败提示、退出状态和请求次数；无效地址在模型请求前拒绝。CLI、SDK、HTTP 不回显配置地址或上游正文。
- 安装组合候选 wheel。真实探索前执行 `doctor --llm-live --require-capability generate_adapters --json`；失败即保存脱敏结果、标记 `llm_live_preflight_not_ready` 并停止，不以离线测试替代。分别验证 Python Docs 的查询和零结果，以及 crates.io 的 5/5/0、固定包新装与 SDK。基于独立普通页面核对返回值，保留失败，不用维护者测试替代独立用户验收。
