# v0.16.368 发布草案

**目标版本：** `0.16.368`
**提交范围：** `v0.16.367..HEAD`

## 用户价值

- ASF Jenkins 的维护版只读 job 列表案例晋级 active，首次使用可通过 `cliany-site demo --case-id apache-jenkins-jobs --json` 完成固定哈希安装、严格校验和非空查询。
- 双语 README、案例库、路线图与官网统一指向已验收的 v0.16.367 公开包；历史 v0.14.1 包仍不适用，已有用户 adapter 不会自动覆盖。

## 验收证据

- 公开 Release 归档重新下载后的 SHA-256 与清单一致：`10ac9f4dc1ce2b4cc364d9fe9517e1ecabd50743885f404040abf8fc248ef18b`。全新 HOME 安装和严格校验通过，只读命令返回 `count=5`、`total=106`。
- PyPI 正式版 `cliany-site==0.16.367` 在独立 Python 3.11 环境重复安装、校验和查询。源码案例库的 fresh-HOME `demo` 首次返回 `installed_now=true`、`row_count=5`，第二次复用返回 `installed_now=false`、`row_count=5`。详见[公开包审计](../user-evidence/2026-10-02-jenkins-public-package-audit.md)。

## 案例库映射

- `cases/manifest.json` 将 `apache-jenkins-jobs` 标为 active，声明已发布包、固定哈希和非空 job 行门禁；`cases/README.md` 提供公开审计链接与首次安装路径。Jira、SuiteCRM、Confluence 保持 active。
- PyPI、npm 和 crates.io 搜索仍为 candidate，`search-extraction-gap` 保持 known-gap；若 candidate 的真实模型预检出现 `llm_live_preflight_not_ready`，不得推进 explore 或宣称已生成可用包。

## 风险与兼容性

- 只证明公开顶层 job 列表的只读查询，不证明每一项都可执行，也不保证 ASF 服务持续可达。
- 本版复用 v0.16.367 公开归档，不重建或重新上传适配器资产；发布流程只更新 Python 包、GitHub Release 和官网。

## 发版前验证

- 运行完整离线测试、案例包严格校验、Ruff/Mypy、网站脚本、wheel/sdist 和 Twine 检查。
- 合并到 master 后，确认最终 SHA 的普通 CI 与 Embodied CI 均通过；target 与 tagged strict release readiness 均通过。

## 发版步骤

1. 最终 master 通过门禁后创建本地 `v0.16.368` tag，严格 tagged readiness 通过后再推送。
2. 等 GitHub Release 与 PyPI 公开可见；本版不重新上传 v0.16.367 的 Jenkins 包。
3. 从 `site/` 向正确的 `cliany.site` 项目部署生产并检查 `www.cliany.site` 别名，最后从全新 master 克隆运行严格远端分发审计。
