# v0.16.350

## What Changed

- Direct Python SDK `explore()` now rejects blank or non-string workflow descriptions with `E_INVALID_PARAM` before creating a workflow explorer.
- Direct Python SDK `navigate()` now rejects unsafe URLs with `INVALID_URL` before creating a browser session.

## Compatibility

Valid non-blank workflow text and whitespace-free HTTP(S) URLs with a host retain their existing behavior. Other SDK methods are unchanged.

## Trust Boundaries

This is a local SDK input-validation change. It does not establish Chrome availability, live LLM success, candidate adapter package availability, metadata validation, online smoke, or third-party workflow success.
