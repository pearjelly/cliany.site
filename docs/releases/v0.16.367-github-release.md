# v0.16.367

## Maintained ASF Jenkins Job Listing

This release includes a separately maintained, read-only Jenkins adapter candidate. The historical v0.14.1 package lacks required schema v3 metadata. The new command reads the public ASF controller's top-level jobs and folders through its JSON API, reports the returned count separately from the total, and accepts only Apache Jenkins HTTPS result links.

The frozen archive passed a pinned-hash install, strict verification, and a read-only query in an isolated HOME. That query returned five rows out of 106 top-level entries. Install the reviewed archive with its exact SHA-256:

```bash
cliany-site market install https://github.com/pearjelly/cliany.site/releases/download/v0.16.367/builds.apache.org-0.16.367.cliany-adapter.tar.gz --sha256 10ac9f4dc1ce2b4cc364d9fe9517e1ecabd50743885f404040abf8fc248ef18b
cliany-site verify builds.apache.org --strict --json
cliany-site builds.apache.org list-jobs --limit 5 --json
```

The package is uploaded separately from the Python distribution. The installer will not overwrite an existing adapter without an explicit `--force`; review a replacement with `--dry-run --json`. The historical generated adapter is unchanged. The Jenkins case remains degraded until the exact public Release asset passes an independent install and replay audit; third-party availability and job totals can change.
