## 用户价值

- Python SDK 的 `doctor()` 和 HTTP `GET /doctor` 现在复用 CLI 的结构化 `checks`、`summary`、稳定硬阻塞错误码和 repair diagnostics，不再返回另一套简化健康检查。
- SDK 自定义 CDP port 继续生效；HTTP 调用可显式传递 `llm_live=true` 和 `require_capability=generate_adapters`，与 CLI 使用同一 live-preflight 门禁。

## 证据边界

- 默认 SDK/API `doctor` 仍只执行本地检查，不调用 provider；只有显式 `llm_live` 才请求 live preflight。
- 最近真实 `cliany-site doctor --llm-live --require-capability generate_adapters --json` 仍返回可重试的 `E_LLM_UNAVAILABLE`；不运行 candidate `explore`，不生成或宣称 package、metadata validation、online smoke、live LLM 或第三方成功。

## 案例库映射

- `cases/README.md` 与 `cases/manifest.json` 保持案例目录为 8 total、4 active、3 candidate、1 known-gap；三个 candidate 的 adapter package、metadata validation、online smoke 仍 pending。
- `search-extraction-gap` 保持 known-gap；`llm_live_preflight_not_ready` 仍是 candidate 晋级前必须修复或重试的 live provider 边界。
- 本轮不修改案例目录，不创建、关闭或改写公网 issue；没有当前 doctor JSON 时也不执行 `--apply --confirm-rewrite`。

## 风险与兼容性

- 既有 SDK 成功 / 错误 envelope 继续保持；完整 CLI 诊断同时保留在 `data` 和 `error.details`，便于现有调用方渐进采用。
- HTTP 对无效布尔参数返回 `400`，Chrome、provider 或必需 capability 暂不可用时保留结构化 envelope 并映射为 `503`；不改变 adapter、workflow job 或发布顺序。

## 发版前验证

- 运行 SDK/API/doctor focused tests、发布说明与官网文档回归、`CLIANY_QA_OFFLINE=1` 全量测试、Ruff、Mypy、`node --check site/script.js`、`uv lock --check`、strict case catalog、`uv build` 与 `uvx twine check`。
- 版本最终化后运行 `uv run --extra dev --frozen python scripts/release_readiness.py --strict --target-version 0.16.338 --remote`；创建本地 tag 后运行 `uv run --extra dev --frozen python scripts/release_readiness.py --strict --release-tag v0.16.338 --remote --remote-name origin`。
- 只有最终 master SHA 的 GitHub CI 与 Embodied CI 都 success 后，才允许创建本地 tag。

## 发版步骤

1. 推送最终 master，等待该 SHA 的 GitHub CI 与 Embodied CI 成功。
2. 运行 `git tag v0.16.338`，再执行带 remote 的 `--release-tag` readiness；失败时删除未推送 tag 并修复。
3. 推送 tag，等待 Release workflow，精确核验 GitHub Release 与 PyPI 专属版本/latest。
4. 将 `site/` 部署到 cliany.site Vercel production，执行 alias inspect 和真实浏览器检查。
5. 最后运行 `python scripts/check_release_publication.py --strict --remote --distribution --json`。
