# v0.16.322

Dependabot now groups GitHub Actions upgrades into one reviewable proposal instead of creating separate branches for each action major. Its configuration comment also avoids carrying a stale inventory of workflow versions.

## Changed

- Future GitHub Actions dependency proposals are grouped for one coherent CI/runtime review.
- Existing workflow action versions, CI jobs, release ordering, and PyPI publication behavior are unchanged.

## Compatibility

This is a maintainer-configuration change. It does not change the cliany-site CLI, adapter schema, SDK, HTTP API, or generated adapter behavior.

## Trust Boundaries

This release does not create, install, or promote a candidate adapter package. It does not prove metadata validation, online smoke, browser workflow success, or live LLM availability. Candidate promotion remains blocked by the real strict live-LLM preflight when that provider is unavailable.
