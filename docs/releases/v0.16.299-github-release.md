# v0.16.299

Structured extraction failures now identify the result rows that need review.

## What Changed

- Failed structured object-row extraction reports can include `data.quality.field_blank_rows`.
- Each field maps to 1-based result row numbers whose value is missing or blank, such as `{"url":[2]}`.
- The shipped search-extraction-gap fixture covers partial URL and snippet fields, while the user docs explain how to use the diagnostic to check a field mapping or page content.

## Compatibility

`field_blank_rows` is an additive optional field for failed structured object-row quality reports. Existing `issues`, `row_count`, `field_names`, `status`, `E_EMPTY_RESULT`, `expects_nonempty`, and successful extraction responses are unchanged.

## Trust Boundaries

Row numbers describe the current extraction result order, not a durable page identity or a repaired selector. This release does not claim a live LLM provider, candidate adapter package, candidate explore, metadata validation, online smoke, or third-party browser workflow succeeded. Candidate promotion evidence remains pending until it is collected and verified.

## Verification
