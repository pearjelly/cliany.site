## 用户价值

- 直接 Python SDK 的 `save_session(domain)` 现在只接受带可选合法端口的主机名，例如 `example.com`、`localhost:9222` 或 `[::1]:9222`。
- 空值、路径、URL 凭据、空白和无效端口会在连接 Chrome 或写入 session 前稳定返回 `E_INVALID_PARAM`，让集成方能够修正调用，而不是把不受约束的标识带入浏览器和持久化路径。

## 证据边界

- 2026-09-04 的真实 `cliany-site doctor --llm-live --require-capability generate_adapters --json` 返回可重试的 `E_LLM_UNAVAILABLE` / `llm_live_preflight_not_ready`；CDP 和本地配置可用，但 live upstream connection error 阻断 candidate `explore`。本次不生成或宣称 candidate package、metadata validation、online smoke、live LLM 或第三方成功。

## 案例库与公开 issue

- `cases/README.md` 与 `cases/manifest.json` 仍记录 8 total、4 active、3 candidate、1 known-gap；三个 candidate 的 adapter package、metadata validation 与 online smoke 仍 pending。
- 本次没有创建、关闭或改写 candidate issue；只改进 SDK 的本地 session-host 边界。

## 案例库映射

- `pypi-project-search`、`npm-package-search` 与 `crates-io-crate-search` 仍必须先通过 live preflight，才能进入 adapter package、metadata validation 和 online smoke 路径。
- `search-extraction-gap` 仍是已知缺口；本次不改变案例状态、adapter 资产或第三方工作流证据。

## 风险与兼容性

- 标准 host、host:port 和 bracketed IPv6 host 保持可用；调用方如果此前将路径、凭据或无效端口传给 `save_session()`，现在会收到明确的本地错误信封。
- 此变更不启动 Chrome、不调用 LLM，也不表示 adapter 或第三方站点已可用。

## 发版前验证

- 运行 SDK、发布说明与官网文档 focused tests、`CLIANY_QA_OFFLINE=1` 全量测试、Ruff、Mypy、`node --check site/script.js`、`uv lock --check`、strict case catalog、`uv build` 与 `uvx twine check`。
- 版本最终化后运行 `uv run --extra dev --frozen python scripts/release_readiness.py --strict --target-version 0.16.352 --remote`；创建本地 tag 后运行 `uv run --extra dev --frozen python scripts/release_readiness.py --strict --release-tag v0.16.352 --remote --remote-name origin`。
- 只有最终 master SHA 的 GitHub CI 与 Embodied CI 都 success 后，才允许创建本地 tag。

## 发版步骤

1. 推送最终 master，等待该 SHA 的 GitHub CI 与 Embodied CI 成功。
2. 运行 `git tag v0.16.352`，再执行带 remote 的 `--release-tag` readiness；失败时删除未推送 tag 并修复。
3. 推送 tag，等待 Release workflow，精确核验 GitHub Release 与 PyPI 专属版本/latest。
4. 将 `site/` 部署到 cliany.site Vercel production，执行 alias inspect 和真实浏览器检查。
5. 最后运行 `python scripts/check_release_publication.py --strict --remote --distribution --json`。
