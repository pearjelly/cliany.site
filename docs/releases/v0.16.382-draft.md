## 用户价值

- 首次 SDK/HTTP 探索不再把提取 Markdown 目录误作已有 adapter，保留实测起始 URL 路径、模型记录及辅助文件。
- 结构化模型失败不再成为 SDK 未捕获异常或 HTTP 纯文本 500。保留认证错误码、安全 retryability/status/phase 详情及旧信封；HTTP 的 503 表示上游依赖不可用，不是调用者登录失败。
- 被拒绝的请求不重复调用；限流、网关与超时保留既有重试边界。失败不产生核心文件，显式 force 也不覆盖已有文件。

复现与范围见[首次生成复核](../user-evidence/2026-10-10-sdk-first-generation.md)及[模型失败复核](../user-evidence/2026-10-10-sdk-provider-errors.md)。PR 85 的一次真实源 SDK 公开站点生成和六次回放通过，不等于本版已完成公开包验收。
