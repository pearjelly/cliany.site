# v0.16.320

Planner-generated candidate issue artifacts now distinguish attached doctor preflight evidence from still-pending adapter package evidence.

## Fixed

- Blocked provider evidence now shows the recovery-and-rerun handoff in planner-generated public issue bodies.
- Attached doctor evidence is labeled separately from package evidence, so a saved preflight never makes candidate `explore` runnable.
- Existing candidate status, package acceptance, source-path redaction, and explicit issue rewrite gates remain unchanged.

## Trust Boundaries

This release does not create, close, or promote GitHub issues. It does not create a candidate adapter package, validate metadata, run an online smoke, replay a browser workflow, or prove a live LLM provider is available.
