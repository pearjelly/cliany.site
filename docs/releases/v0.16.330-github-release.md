# v0.16.330

## Fixed

- Candidate issue audit now reports GitHub API or network transport failure as retryable `E_GITHUB_UNAVAILABLE`.
- The structured error tells maintainers that remote issue state was not read, so the audit does not synthesize `missing` states or enter an apply path.

## Compatibility

- Current, stale, missing, duplicate, and unexpected issue-state semantics are unchanged when GitHub issue data is available.
- CLI, adapter commands, SDK, HTTP API, case statuses, and release ordering are unchanged.

## Trust Boundaries

- A transport failure is not candidate evidence and does not change any public issue. Retry the read before reviewing or applying a rewrite.
