# v0.16.340

## Fixed

- Strict publication audit now retries short-lived Git remote and GitHub/PyPI JSON transport failures before reporting a blocker, reducing unnecessary manual reruns after a transient network interruption.
- Persistent remote failures still produce the original blocking audit evidence, while HTTP responses are not retried. An unreachable or mismatched public artifact can never be reported as published.

## Compatibility

- Existing audit fields, release gates, and publication decisions are unchanged. The bounded retry applies only to transport failures while reading remote refs and JSON endpoints.

## Trust Boundaries

- A successful audit remains evidence of the remote refs and public artifacts it actually reads; a retry is not evidence that GitHub, PyPI, Vercel, Chrome, or a third-party workflow is available.
- Candidate adapter package promotion remains gated on a real successful live LLM provider preflight.
