# v0.16.375

## Readable Quickstart on Small Screens

The website quickstart now keeps Copy controls separate from command text. Its longer `explore` example wraps into readable shell-continuation lines on screen, while Copy still supplies the original executable command. Tablet-width quickstart cards use one column so environment variable names remain legible.

On narrow phones, the extended feature grid no longer creates an implicit second column or stretches its cards beyond the viewport. Long diagnostic field names wrap instead of causing page-wide horizontal scrolling. Advanced contribution, maintainer, and experimental-provider notes start collapsed so the feedback path is easier to reach; their content remains available on demand. The desktop header now keeps navigation clear of the brand and switches to its menu before space runs out. These are website presentation fixes; the CLI, adapter format, and read-only case catalog are unchanged.

The public Python documentation browser adapter remains a candidate. Its [first-time user trial](https://github.com/pearjelly/cliany.site/issues/55) still needs independent feedback; this release does not claim that an independent user completed the workflow.
