# v0.16.375

## Clean Install Startup

The package now requires the verified `browser-use==0.12.4` version. A fresh install with the former unconstrained dependency could resolve to 0.11.13 with MCP 2.3.0 and fail during import with missing `pydantic_settings`, even for `cliany-site --version`. The development lockfile already used 0.12.4, so locked tests alone did not catch that installation failure. Future browser-use upgrades require a compatibility review.

## Readable Quickstart on Small Screens

The website quickstart now keeps Copy controls separate from command text. Its longer `explore` example wraps into readable shell-continuation lines on screen, while Copy still supplies the original executable command. Tablet-width quickstart cards use one column so environment variable names remain legible.

On narrow phones, the extended feature grid no longer creates an implicit second column or stretches its cards beyond the viewport. Long diagnostic field names wrap instead of causing page-wide horizontal scrolling. Advanced contribution, maintainer, and experimental-provider notes start collapsed so the feedback path is easier to reach; their content remains available on demand. The desktop header now keeps navigation clear of the brand and switches to its menu before space runs out. CLI arguments, adapter format, and the read-only case catalog are unchanged.

The public Python documentation browser adapter remains a candidate. Its [first-time user trial](https://github.com/pearjelly/cliany.site/issues/55) still needs independent feedback; this release does not claim that an independent user completed the workflow.
