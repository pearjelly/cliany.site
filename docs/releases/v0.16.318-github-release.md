# v0.16.318

Doctor-backed candidate handoffs now preserve evidence identity without exposing a maintainer's local file path in a public issue.

## Fixed

- Public candidate issue templates render `values_sha256`, gate state, and extracted doctor fields instead of the saved doctor JSON path.
- Planner-generated issue drafts use `<saved-doctor-json>` in public reproduction commands; local audit JSON and reviewed metadata still retain the real source path for traceability.
- Candidate issue audits continue to require explicit `--apply --confirm-rewrite` before any matched stale public body is changed.

## Trust Boundaries

This release does not create, close, or promote GitHub issues. It does not create a candidate adapter package, validate metadata, run an online smoke, replay a browser workflow, or prove a live LLM provider is available. The real 2026-08-13 live preflight remained blocked by retryable `E_LLM_UNAVAILABLE`.
