# v0.16.356

Fixed a control-flow error in the shared action executor: click, type, select, and submit could be reported as successful without reaching browser dispatch. Browser routing and API failure fallback now execute the browser action.

Dry-run no longer dispatches page actions. A real Chromium regression demonstrates that v0.16.355 mutated a form during dry-run; the fixed executor leaves it unchanged and correctly fills, selects, and clicks during actual replay.

API success now appears in progress and execution reports. Browser handler failures remain failures when continue-on-error is enabled, while later steps still run.

This release fixes the shared executor. Separate generated-CLI atom compatibility and complete SDK/HTTP/CLI workflow parity still require follow-up; no live LLM or candidate promotion is claimed.
