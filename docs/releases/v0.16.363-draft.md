# v0.16.363 发布草案

**目标版本：** `0.16.363`
**提交范围：** `v0.16.362..HEAD`

状态：2026-09-28 第三个且最后一个发布候选；今日达到标签上限后不再推送新 tag。

## 用户价值

- 从官方 PyPI 新装 v0.16.362 的真实重放发现：外层 `on_NavigateToUrlEvent` 30 秒超时仍会误报为 `E_UNKNOWN`。本版将它与已处理的 `Page.navigate()` 20 秒超时统一归为 `E_PAGE_NOT_READY / navigation_timeout`。
- 无关 `TimeoutError` 和 RuntimeError 继续保持原分类，避免把模型、磁盘或其他运行时错误错归因于网页。

## 当前证据

- 官方 PyPI simple 索引的无缓存安装成功，v0.16.362 的真实浏览器重放出现外层事件超时。默认安装索引曾短暂滞后，不能仅靠版本专属 PyPI JSON 判断新用户安装成功。
- 定向 CLI 回归覆盖两种导航超时与两种无关错误；最终全量测试和 CI 须在最终提交上复核。
- [crates.io navigation evidence](../user-evidence/2026-09-28-crates-navigation.md) 记录 HTTP 403、浏览器超时及没有生成 adapter 的边界。

## 案例库映射

- `cases/manifest.json` 的 `crates-io-crate-search` 仍是 candidate，`adapter_package` 仍 pending；`cases/README.md` 的候选流程不变。
- `pypi-project-search` 的在线搜索仍待正常页面验证；`search-extraction-gap` 保留抽取质量边界。

## 风险与兼容性

- 分类仅识别明确属于 `on_NavigateToUrlEvent` 的 `TimeoutError`；不能证明网页在其他网络不可用，也不绕过 HTTP 403 或验证页。
- 真实模型探索须逐次做 `doctor --llm-live --require-capability generate_adapters` 预检；遇到 `llm_live_preflight_not_ready` 应停止探索并保留证据。
- Jev 的实时 TypeSafe 准确率未测量，本版不改变 Jev 权限。
