# v0.16.392

Recorded explorations that fail now retain the existing planning-time AX observation, raw model response when available, preceding turn trace and fixed reason in a separate private failure journal. This makes a rejected plan inspectable without reconstructing it from later passing attempts.

## Local Diagnosis Without Replaying Actions

The journal is stored at `recordings/<domain>/<session>/failure.json` under the selected runtime directory. It is explicitly not an execution receipt. Proposed or deferred actions are not silently executed, renumbered, turned into ordinary successful StepRecords or emitted as adapters. Existing semantic refusal, action history and all model/action/shared-repair budgets stay unchanged.

No extra browser observations or model calls are made to create this evidence. No-record adds no journal writes. New session directories request mode700 and new journal files mode600; existing journals are never overwritten. A failed write may leave an incomplete new file, but must not replace the original exploration error. Cancellation propagates unchanged. Successful recording format is unchanged.

Raw page/model evidence can be sensitive. Keep it local/private, review it before sharing, and never upload a full recording, profile or journal to a public issue. Public JSON errors do not embed the journal. See the [recording guide](https://github.com/pearjelly/cliany.site/blob/master/docs/exploration-recordings.md).
