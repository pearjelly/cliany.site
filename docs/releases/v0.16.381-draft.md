## 用户价值

HTTP 状态优先决定重试，被拒绝的请求只调用一次；401/403 在 CLI 与 live doctor 保留 `E_LLM_AUTH_FAILED`。单次错误事件与警告只记录固定类别、状态和 retryability，不回显上游正文或私密地址。typed timeout 保留有界恢复，旧进度 callback 不变。见[复核](../user-evidence/2026-10-10-safe-llm-retries.md)和[使用边界](../llm-retry-diagnostics.md)。

## 风险与兼容性

HTTP 429/500/502/503/504 的原有重试集合和 OpenAI 120 秒网络操作超时不变；不是整个 workflow 的时限。新错误 callback 为可选，不要求旧 reporter 实现。其他旧进度事件仍可能含 workflow URL，不能宣称整个 stderr 无私密内容。保留语义定位、固定哈希、严格验证、旧 adapter 不迁移和生成文件不可手改边界。PR CI 离线且零真实模型密钥；不声明 SDK/HTTP explore 信封已对齐。
