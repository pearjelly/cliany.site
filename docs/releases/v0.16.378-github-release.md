# v0.16.378

## Truthful Command Timing and Readable Documentation Links

CLI metadata now distinguishes measured invocation time from unavailable timing with optional `meta.duration_measured`. Only an explicit true makes integer `duration_ms` usable; a real submillisecond invocation may round down to zero. Monotonic per-invocation contexts separate nested calls, restore their parents and invalidate expired copied contexts. This fixes misleading metadata, not workflow speed.

The boundary is root CLI entry through metadata construction, not whole-process startup, later output/cleanup, CPU time, LLM-only time or an HTTP request deadline. Envelope version 1 and other fields remain; legacy SDK/HTTP top-level responses and doctor's per-check durations are unchanged. Newly generated adapter metadata samples the shared helper, while historical generated modules are not rewritten and may retain unavailable parent timing.

Documentation fragment headings stay below the sticky header while native links, keyboard navigation, reload and browser history are preserved. First-use guidance selects an empty cliany runtime directory with normal OS HOME and separately isolated browser profiles/CDP endpoints.

The unchanged public Python docs archive passed installed PyPI v0.16.377 strict checks and browser replays. All 100 returned title/link rows matched an independent normal page's ordered prefix, but that page had 131 results: collection remains capped. This is maintainer evidence, not independent first use or general browser availability. The case remains candidate, and the alpha audit still concludes not ready.
