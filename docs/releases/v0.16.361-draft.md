# v0.16.361 发布草案

**目标版本：** `0.16.361`
**提交范围：** `v0.16.360..HEAD`

状态：2026-09-28 发布候选；以最终提交、CI、tag 和公开分发检查为准。

## 用户价值

- PyPI 候选案例不再要求用户重新生成或上传已经公开发布的 adapter 包。`cases` 将下一步明确指向尚未通过的只读在线搜索。
- 发布审计正确处理附注 Git tag，避免已发布版本被误报为缺少远端 tag。

## 证据与边界

- GitHub Release v0.16.360 的 PyPI adapter 资产 SHA-256 与记录一致；公开 HTTPS 安装和 `verify --strict` 在全新 HOME 通过。
- PyPI 的正常浏览器搜索尚未稳定通过；遇到 `Client Challenge` 时案例保持 candidate，不绕过站点验证。
- Jev 的实时 TypeSafe 准确率未测量；本版本不扩大 Jev 的权限或功能承诺。

## 案例库映射

- `cases/manifest.json` 把 `pypi-project-search` 的公开包和元数据证据标为 complete，在线搜索仍为 pending；`cases/README.md` 的候选案例流程继续适用。
- `search-extraction-gap` 仍记录抽取质量边界；本版本不改变抽取或重试逻辑。

## 风险与兼容性

- PyPI 搜索仍可能遇到 `Client Challenge`，不能据此晋级或绕过验证。
- 即使本次真实模型预检通过，后续探索仍须逐次运行 `doctor --llm-live --require-capability generate_adapters`；遇到 `llm_live_preflight_not_ready` 应停止探索并保留错误证据。
- 本版本仅改变发布审计与案例证据，不修改已有生成 adapter 或用户会话。

## 发版前验证

- 完整离线测试、Ruff、Mypy、案例目录与目标包校验、网站 JavaScript 检查、wheel/sdist 构建与 Twine 检查。
- `release_readiness.py --strict --target-version 0.16.361 --remote --remote-name origin --json`。
- 推送最终提交后，确认同一 SHA 的普通 CI 与真实浏览器 CI 成功。
