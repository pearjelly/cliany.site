# v0.16.352

## What Changed

- Direct Python SDK `save_session(domain)` now accepts only a session host with an optional valid port before opening Chrome or persisting a session.
- Empty values, paths, URL credentials, whitespace, and invalid ports return the stable `E_INVALID_PARAM` envelope, while regular hosts, host:port values, and bracketed IPv6 hosts remain supported.

## Compatibility

Existing callers that pass a host such as `example.com`, `localhost:9222`, or `[::1]:9222` keep their behavior. Callers that previously passed a path-like or credential-bearing storage identifier now receive a repairable local error response.

## Trust Boundaries

This is a local SDK input-validation change. It does not establish Chrome availability, live LLM success, candidate adapter package availability, metadata validation, online smoke, or third-party workflow success.
