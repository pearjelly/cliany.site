# v0.16.364

## Clearer Navigation Failures for CLI and SDK

Read-only replay of the published PyPI adapter exposed a browser navigation timeout. The `browser navigate` command now reports observed navigation timeouts as `E_PAGE_NOT_READY` with a site-access hint, rather than confusing them with a lost Chrome CDP connection. Python SDK `navigate()` applies the same distinction instead of returning a generic execution failure. Unrelated disconnects retain their existing errors.

The PyPI adapter package installs and verifies from its public release asset, but the online search remains unverified: this run timed out, and a separate request saw PyPI's `Client Challenge` page. The case stays `candidate`; this release does not bypass site controls or claim a successful search workflow.
