# v0.16.389

## Diagnose Remote Installation Without Exposing Upstream Content

Remote `market install` failures retain `INSTALL_FAILED` and nonzero exit, with `error.details.stage=download`, a fixed `reason` and a valid numeric HTTP `status_code` when available. The categories are `http_error`, `timeout`, `tls_certificate_error`, `tls_error`, `network_error`, `incomplete_response` and `download_failed`. Repair hints distinguish missing assets, access rejection and certificate trust instead of blaming archive format for transport failures. `demo` preserves the upstream diagnostic and stops before verification/query.

Public messages omit URL login credentials, query and fragment; new diagnostics omit raw exception/response/header content and incomplete response bytes. Certificate verification exceptions are separated from ordinary package-validation ValueErrors. Unknown failures remain unknown rather than inventing a network cause.

## Evidence And Limits

The [dated evidence](https://github.com/pearjelly/cliany.site/blob/master/docs/user-evidence/2026-10-17-remote-install-diagnostics.md) preserves real published-v388 archive download failures, failing baseline regressions, an incomplete first fix and real controlled HTTPS checks. Earlier failures' uncaptured causes cannot be reconstructed; later successful downloads are not first-attempt rescoring or a reliability rate. Controlled HTTPS uses an isolated test CA in child processes only, with certificate verification enabled.

Successful payloads, source URLs actually requested, fixed hashes, TLS verification, no-overwrite, package validation, generated files and existing timeout/retry policies remain unchanged. No automatic retries, complete-command deadlines, new model exploration or case promotion. Final source/master and official-package/publication gates require their own receipts. Independent first-use reports remain **0/2**; the [fixed human trial](https://github.com/pearjelly/cliany.site/blob/v0.16.387/docs/first-use-trial.md) stays at published 0.16.387, preserving original failures and assistance timing.
