# v0.16.399

Strict live doctor now checks whether the model's reply can be read as a JSON object. An HTTP success with an unusable reply no longer marks adapter generation as ready. The diagnostic distinguishes malformed JSON from a non-object reply without displaying the model's response. The probe makes no additional request.

The final CLI, SDK, and HTTP exploration result now retains an optional, sanitized `error.details.reason` from the final model attempt. Callers can distinguish a connection failure, timeout, or rejected request without retaining progress logs. Existing error codes, HTTP status handling, and retry budgets are unchanged.

[Failure and retry diagnostics](https://github.com/pearjelly/cliany.site/blob/master/docs/llm-retry-diagnostics.md) describe the boundary. The [original false-ready observations](https://github.com/pearjelly/cliany.site/issues/128) remain recorded. Passing a model probe does not establish workflow success. The independent trial stays fixed at v0.16.387; no case is promoted by this release.
