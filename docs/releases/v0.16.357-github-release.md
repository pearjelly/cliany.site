# v0.16.357

Release candidate notes. Not published yet.

## Reliable Generated Commands

- Preserve action order and target identity, and keep parameters attached to their owning commands.
- Return extracted data and meaningful failures consistently through CLI, SDK, HTTP, workflow, and batch entrypoints.
- Restore saved cookies before navigation and respect explicit browser routing.
- Reject ambiguous or conflicting recorded targets, invalid completion responses, exhausted exploration, and invalid action partitions.

## Experimental Jev Finder

`browser find --by intent --value ... --allow-remote` selects from actual AXTree candidates without performing browser actions. It requires `TYPESAFE_API_KEY` and sends intent, element names, and roles to TypeSafe. Live accuracy, latency, and cost remain unvalidated.

## Upgrade Notes

Regenerate existing adapters to receive code-generation fixes; existing generated files are not rewritten. Built-in browser batch execution is now sequential even when higher concurrency is requested, because independent browser-session isolation is not implemented. Custom executors retain their concurrent path.

Jenkins and Confluence historical demos are degraded. Confluence's original keyword example still returns no rows; a successful envelope is no longer sufficient evidence. No replacement demo package is included.

The verified development baseline passed 2985 offline tests and real Chromium integration, but does not establish live-model discovery, arbitrary website reliability, localStorage restoration, or concurrent browser isolation. Revalidate the final release commit before publishing these notes.
