# v0.16.376

## Isolated Trials With the Normal OS Home

Set `CLIANY_RUNTIME_HOME` before starting the CLI to choose a separate directory for adapters, session files and persisted runtime artifacts. The default remains `~/.cliany-site`. Demo install, strict verification and read-only query subprocesses use the parent's selected directory, including an explicitly configured in-process home. The benchmark runner uses the same inheritable setting.

Previously, an isolated parent could choose installation while its child found an unrelated adapter in the default directory and stopped. Command indexes, repair/heal caches, existing-adapter context, recordings, default screenshots and Obscura cache/PID files also now follow the configured directory. Fixed-hash installation, strict verification and refusal to overwrite remain enforced. CLI arguments, JSON and adapter formats are unchanged; Chrome's OS home, explicitly chosen browser profiles, XDG model configuration and system Keychain are not relocated.

A maintainer's fresh isolated public Jira trial installed the pinned archive and returned five SPARK issues, then reused the installation. A separate direct API check confirmed one returned issue's title and status. This is an API-backed maintainer check; independent first-user acceptance and live browser-generation reliability remain open.
