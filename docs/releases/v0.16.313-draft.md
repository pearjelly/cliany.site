# v0.16.313 发布草案

**目标版本：** `0.16.313`
**提交范围：** `v0.16.312..HEAD`
**提交范围：** `v0.16.313..HEAD`
**发布主题：** 修复生产官网脚本语法错误，恢复首页完整渲染。

完成 version bump 后，target-mode readiness 会检查占位锚点 **提交范围：** `v0.16.313..HEAD`；该锚点不改变实际 release diff。

## 用户价值

v0.16.312 发布后的真实浏览器检查发现 `site/script.js` 在英文 maintainer translation 中使用单引号定界，同时包含未转义的 `manifest's`。浏览器因此抛出 `SyntaxError: Unexpected identifier 's'`，首页首屏只剩导航骨架，主体内容没有完成渲染。

本版把该长英文文案改为双引号 JavaScript 字符串，并增加站点回归以锁定 quote-safe 定界形式。`node --check site/script.js` 与生产浏览器检查共同验证脚本可解析、首页主体可见且控制台无该语法错误。

## 案例库映射

- [cases/README.md](../../cases/README.md) 与 `cases/manifest.json` 中四个 active case、三个 candidate package-search case 和 `search-extraction-gap` known gap 均不变。
- 本版只修复官网静态 JavaScript 可执行性，不改变 doctor、adapter runtime、candidate evidence contract 或案例状态。
- 2026-08-11 的真实 live-LLM 预检仍由 evidence extractor 归类为 `llm_live_preflight_not_ready`；candidate 晋级门禁没有因官网修复而改变。
- candidate adapter package、metadata validation 与 online smoke 仍为 pending；本版不声称 live LLM 或第三方 workflow 成功。

## 风险与兼容性

- 修改仅限翻译字符串定界符；英文可见内容不变。
- v0.16.312 的 GitHub Release 与 PyPI 已公开，不能改写其 tag；官网修复以新的 v0.16.313 补丁版本完整发布。
- 真实浏览器复查必须确认首页主体渲染、`Current baseline: v0.16.313` 可读取，并且控制台没有 script syntax error。
