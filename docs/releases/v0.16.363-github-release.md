# v0.16.363

## Complete Navigation Timeout Diagnosis

A fresh installation of v0.16.362 from the official PyPI index exposed a second browser navigation timeout. The browser event bus interrupted `on_NavigateToUrlEvent` after 30 seconds; despite the page-navigation fix in v0.16.362, `explore --json` still returned generic `E_UNKNOWN` for this outer timeout.

This release recognizes that navigation-handler `TimeoutError` and returns `E_PAGE_NOT_READY` with `reason=navigation_timeout` and `phase=navigation`. Other timeouts and unrelated runtime failures keep their existing classification. The focused CLI regression covers both observed navigation timeout forms and the unrelated-error boundary.

The crates.io search page returned HTTP 403 from the maintainer network and remains unavailable to this read-only exploration attempt. No adapter was generated or case promoted, and the change does not bypass site controls. PyPI search and Jev live-quality claims remain unchanged.
