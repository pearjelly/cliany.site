# v0.16.394 发布草案

**目标版本：** `0.16.394`
**提交范围：** `v0.16.393..HEAD`（最终 master 为准）
**状态：** 候选准备；源码、测试和已发布分发分别核验。

## 用户价值

本地 CDP 端口返回非浏览器响应时，不再抛出通用属性异常或自动启动另一个浏览器；doctor 给出浏览器不可用和检查端口的提示。保留已有有效浏览器复用和空闲端口启动。

Click 命令执行中取消返回明确的 `E_CANCELLED` 和非空提示，直接键盘中断退出 130；EOF 和显式取消退出 1。已有生成命令保留取消错误并停止后续动作，但其外层仍按原约定退出 1；取消后不调用可选自愈，不改写已有生成文件。

## 案例库映射

核对 cases/README.md、cases/manifest.json 和四个 active 固定包。search-extraction-gap 仍为候选；真实模型探索前执行 `doctor --llm-live --require-capability generate_adapters --json`，`llm_live_preflight_not_ready` 或上游不可用时停止并保留失败，不晋级案例。独立试用仍固定已发布 0.16.387，A/B、首次失败、帮助和重试分别记录。

## 风险与兼容性

精确提交27c58ebc的普通 CI 使用 pytest9.2.0/pytest-benchmark5.3.0，九个性能 fixture 因访问已移除的 `_nodeid` 而报错。隔离环境复现9个错误，仅切换 pytest9.1.1后9项通过。测试依赖增加 `<9.2` 上界；运行时依赖、测试和 CI jobs 不变。修订后须重新完成所有精确提交门禁，旧通过结果不挪用。

本次检查不认证响应方身份，也不能消除端口检查和启动之间的并发竞争；旧的间歇性 Chrome 启动超时原因仍未知。不修改用户原有浏览器、会话或生成 adapter。保留固定387维护者首跑下载失败和后续重试，维护者测试不计独立用户。

受控信号实验复现原空错误信封，另一次修改后实验在 120 秒超时且缺少信号送达证据；后续单次通过不能覆盖该失败。原页面就绪警告的成因仍未知，详见 Issue 116。先完成新提交的受控取消、完整浏览器、真实模型和所有发布门禁。
