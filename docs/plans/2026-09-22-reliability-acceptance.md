# 下一阶段：以真实任务闭环验收

日期：2026-09-22。公开基线 v0.16.356；本日后续修复均为 Unreleased。

## 已有证据

- 真实 Chromium 上，实际保存的适配器可经 CLI、SDK、HTTP、workflow、串行 batch 返回两个不同输入的结果；显式浏览器路由不操作备用浏览器。
- 失效录制编号可通过保存的名称和角色回放。没有验证同名同角色的消歧。
- 探索链路仅替换模型回答，保留真实快照、执行、生成与存储；新进程回放会检查业务输出。它不证明真实模型的发现能力。
- 失败状态、数据保留、JSON 流隔离、字段完整性、条件及数组变量已补回归。测试总数不作为实际任务成功率。

## 紧接着做什么

1. **动作次数与顺序（已修复，Unreleased）**：独立页面计数器复现单次命令提交两次；六种内联/reuse_atom 组合暴露自追加、覆盖和复用动作被去重的问题。模板与复用动作保留逻辑已修复。旧适配器须重新生成；网络重试下的全局 exactly-once 不在本次保证范围。
2. **上下文与并发**：验证新进程恢复登录、明确目标 tab，并复现 CliRunner 并行隔离风险。通过标准是数据与页面副作用不串到另一项任务；不能用模拟执行器通过代替浏览器并发支持。
3. **语义消歧**：同名同角色多个候选不得任意选择。验证新增/移除控件与编号复用，保留诊断信息，禁止 CSS 兜底。
4. **探索产物可信度（部分修复，Unreleased）**：步数耗尽且尚未确认完成时已改为失败，不再把部分动作合成命令，录像标记为未完成。显式声明命令的动作分区须按录制顺序覆盖每个动作恰好一次，不再平均切分或静默过滤无效索引。损坏的模型回答不再转换为完成状态；已录制动作但未声明命令时拒绝生成回退命令。重复提取和完成声明的业务证据仍待验证。探索记录可以保存，但不能自动等同于可复用命令已验收。
5. **公开只读价值集**：先完成上述核心门禁，再选择三个任务，分别记录生成与重放成功率、输入变化、耗时、成本、人工干预及独立结果 oracle。候选案例只在包、安装、严格验证及在线检查均通过后晋级。

## 发布与范围

保留每天至少一版的目标及当前每日最多三个标签的流程限制。下一可用窗口先核对未完成发布，然后合并 Unreleased 修复，完成准确提交的 CI、GitHub Release、PyPI 精确版本与官网生产核验。不得将尚未发布的功能描述成 v0.16.356 已包含。

不扩大 provider、TUI 或服务化功能面；HTTP 暂按单用户本地入口验证，不声称多租户隔离。真实模型故障单独报告，不用离线脚本冒充模型探索证据。外部用户独立完成 quickstart 的证据仍缺失。
