## Unpublished Correction Boundary

On the same observed origin/path, equal extraction mode/fields and uniquely re-grounded AX identity identify a repeated collection. A form's query update may occur after the preceding turn's URL was captured, so query-only changes are not invented navigation evidence. No raw selector-string fallback is used.

The proposed duplicate is refused before execution or recording, using the existing single shared semantic-plan correction allowance. The prompt can complete with `actions=[]` and commands covering the existing action indices; if more work is needed, it must plan a different scope. Persistent repetition, exhausted shared allowance or the last step fails with `duplicate_completed_extract`. Nonterminal repetition cannot bypass this observation check merely by setting done=false. A correction can consume another model invocation within the existing allowance; retry limits and step budgets are not increased.
