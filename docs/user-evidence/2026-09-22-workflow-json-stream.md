# 工作流 JSON 输出与诊断日志隔离

日期：2026-09-22。状态：Unreleased，公开版本仍为 v0.16.356。

## 复现

使用真实 Click 命令先向 stderr 写诊断日志，再向 stdout 写成功或失败信封。旧执行器解析混合输出，解析失败后把零退出码转换成成功：成功数据变成 raw_output，失败信封也被当作成功。

另外验证空 stdout、普通文本、截断 JSON、连续两个 JSON 对象。旧实现均继续执行后续步骤。新增六项测试修复前全部失败，修复后相关文件 23 项全部通过。

## 修复与兼容性

执行器只解析 stdout。stderr 不再参与 JSON 解码；无效 JSON 返回 STEP_FAILED，错误消息保留退出码与输出供排查。已有有效结果对象仍遵循 ok 优先、兼容 success、非零退出不得成功的规则。

执行器一直传入 --json，所以删除了无效 JSON 的 raw_output 成功兜底。第三方适配器必须遵守此输出约定；仅输出普通文本的命令不再被静默视为成功。本修复不增加浏览器、公网或 LLM 证据，也不解决 CliRunner 并发隔离问题。
