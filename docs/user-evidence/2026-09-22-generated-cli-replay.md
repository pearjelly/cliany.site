# 生成 CLI 的浏览器上下文与数据回放

日期：2026-09-22。状态：Unreleased；对外已发布版本仍为 v0.16.356。

## 测试方法

扩展 `test_generated_adapter_returns_real_form_data`：实际保存生成器产物，在独立 Python 进程中运行该 adapter 的 read-name 命令，显式传入目标浏览器 CDP URL。环境变量指向另一个隔离的默认浏览器。两者都由测试启动，运行时 HOME 隔离，不连接日常 Chrome。

每次用新的 CLI 进程，分别输入 Ada、Grace，读取本地表单输出。默认浏览器的所有页面必须保持 about:blank，避免“在错误浏览器中成功”也通过验收。

## 复现与修复

旧版本测试失败：默认浏览器被导航，说明嵌套 CliRunner 丢弃了外层显式 CDP URL。修复后默认浏览器保持不动，但完整命令仍失败，继续定位到结构化提取的结果类型：browser-use 返回 JSON 文本，CLI 提取没有像共享执行器那样解码，质量检查将其当作非数组。

- run_atom 从当前根 Click 上下文传递 cdp_url/headless，避免回退到另一个连接。
- 录制的 type 动作使用 --clear，与共享执行器的替换语义一致；独立 browser type 的默认保留原值行为不变。
- 把既有 JSON 解码 helper 放入 extract 模块，由共享执行器和结构化提取命令共同使用。已有对象保持原样；无效 JSON 不会被伪造为成功数据。

修复后两次独立进程均取得对应结构化字段，质量检查通过，默认浏览器保持不变。27 项相关回归通过，包括根上下文传递、clear 路由与 JSON/对象两种返回类型。

完整离线测试 2842 项通过（6 项既有警告），Ruff 与 Mypy（123 个源文件）通过。
