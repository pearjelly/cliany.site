# 从探索到新进程回放

日期：2026-09-22。状态：Unreleased，公开版本仍为 v0.16.356。

新增真实 Chromium 测试只替换 _get_llm 返回的模型。模型根据实际捕获的 AXTree 引用返回确定性 JSON；观察包装器仍调用真实 capture_axtree，不伪造页面信息。动作执行、JSON 解析、探索完成门禁、ExploreResult、生成器、保存与新 CLI 进程均使用真实实现。

初次测试失败：快照使用 page.url/page.title()，锁定 browser-use 提供的实际接口是 get_url()/get_title()。异常被吞掉后，来源 URL、页面标题与动作 page_url 均为空，生成代码导航到 https://127.0.0.1 而不是带端口和路径的已观察地址，最终连接失败。

修复改用支持的异步接口。测试断言探索产物保留实际 URL 和 textbox 语义，独立读取页面确认探索真的提交 Ada，再保存适配器并在两个独立 CLI 进程中验证 Ada/Grace 返回值，备用浏览器保持 about:blank。该完整新增用例通过。

同时发现生成模板首个内联组自追加，会重复动作；本轮没有将最终值正确包装成次数正确。此项已列入下一验收计划首位。此测试只代表离线模型边界集成，不证明真实模型发现能力、所有参数类型或公网案例可靠。

本地全量离线回归 2894 项通过；Ruff 通过，Mypy 检查 123 个源文件通过。

等待下一发布窗口统一更新 GitHub Release、PyPI 和官网。
