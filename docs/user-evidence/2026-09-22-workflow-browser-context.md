# 工作流浏览器上下文传递

日期：2026-09-22。状态：Unreleased，公开版本仍为 v0.16.356。

## 问题与修复

工作流执行器重新调用根 CLI 时没有传递外层根选项。即使用户显式指定 --cdp-url，子命令仍会使用环境中的默认浏览器。

执行器现在在创建时保存根 --cdp-url、--headless、--sandbox、--force-browser 和 --diagnose，并在子命令前传入。这也避免在批处理工作线程中读取已经不存在的 Click 上下文。没有修改生成的适配器，也没有改变自定义执行器接口。

## 验证边界

- 两个独立 Chromium 实例：命令行显式连接主浏览器，环境变量指向备用浏览器。
- 使用真正生成并保存的适配器，经独立 CLI 进程执行 workflow run；修复前备用浏览器被导航，测试失败，修复后 Ada、Grace 两次真实表单回放返回正确数据，备用浏览器保持 about:blank。
- 同一回归扩展到默认串行 workflow batch；检查返回数据及备用浏览器状态。
- 独立参数测试通过真实 Click 命令读取继承后的根选项，包括执行器离开父上下文后，以及单个工作线程内执行的情况。
- 不声明多个 CliRunner 同时调用或多个任务同时操作同一浏览器安全；不声明公网案例、LLM 探索或新的候选案例通过。

本地全量离线回归 2870 项通过；Ruff 通过，Mypy 检查 123 个源文件通过。
