## Correction Boundary

After all overrides are assembled, validate the argument set together against executable fields owned by that command. Use the same allocated Click/Python variable names as the renderer and its existing substitution alias precedence, including reserved names. A shared naming helper removes duplication without changing that allocation. Only tokens that actually reach consumed input/select values, navigation URLs, action target names or applicable legacy extraction selectors count; descriptions and ignored values do not. Grounded semantic extraction does not acquire a raw-selector parameter fallback. Existing reuse-atom key-before-value parameter mapping is checked using the renderer's existing precedence. This is static effect validation, not proof of intended values, safe external URLs, arbitrary metadata correctness or task success.

Missing effects and later-clobbered arguments fail with ParameterBindingError rather than emitting a no-op option. Preserve existing type/select ownership validation and valid inline/URL placeholders, atom parameter mappings and aliases. The explorer previews actual action refs/AX metadata, URLs and atom parameters, then checks all arguments together before executing/recording a declared completion. It continues using the existing single shared semantic repair; keeping a name while removing its binding cannot evade it. No action/navigation/model retry increase, history deletion, output deduplication, generated-file patch, archive change or case promotion.
