# 生成命令的语义目标回放

日期：2026-09-22。状态：Unreleased，公开版本仍为 v0.16.356。

生成命令原先优先使用 ref，即使已经保存 target_name 和 target_role。AXTree 编号变化时，这会忽略可用语义信息，造成找不到元素或操作错误目标的风险。

点击、输入、选择和提交的录制回放现在优先传递保存的名称及角色。四个浏览器命令新增 --role，用于在名称模糊匹配前按 AXTree 角色筛选；没有名称的旧记录仍使用原始 ref。没有加入 CSS 兜底，未修改生成文件。

验证包括四种动作的调用参数、同名不同角色的筛选、角色不存在时不返回其他角色。现有真实 Chromium 生成适配器回归改为携带不存在的旧编号，分别经过 CLI、SDK、HTTP、workflow 与默认串行 batch，仍要求返回 Ada/Grace 表单结果并保持备用浏览器未被操作。

验证范围不包括同名同角色多个候选的消歧，也不证明所有动态页面变化均可修复。无名称记录仍依赖编号；这是明确保留的兼容边界。没有新增公网或 LLM 探索证据。

首次真实回归发现快照把标签名当作角色，导致 textbox 无法匹配 input。快照现在优先读取 ax_node.role，并保留 tag_name 兼容旧录制的标签角色。无障碍角色缺失时仍回退标签名。

最终本地全量离线回归 2893 项通过；Ruff 通过，Mypy 检查 123 个源文件通过。
