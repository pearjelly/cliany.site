# 生成命令的空结果与字段完整性

日期：2026-09-22。状态：Unreleased，公开版本仍为 v0.16.356。

## 复现与修复

旧质量汇总优先把任意 empty 提取归为整体 empty。因此 expects_nonempty=false 的命令会放行已有记录但字段全空的结果，也会放行同时包含空提取和部分字段缺失的结果。

新增测试真正生成 Click 适配器并调用命令，只替换浏览器执行边界返回受控内容，不模拟 summarize_extract_quality。三个错误场景修复前均被返回成功：一条全空字段记录、空提取后有缺失字段记录、反向顺序。真正零条结果的正向用例保持成功。

共享汇总现在让 partial 或 field_blank_rows 优先于 empty，与 SDK 判断一致。单步原始质量证据保持不变，整体为 partial 时由已有门禁返回 E_EMPTY_RESULT。未修改生成的适配器文件，未改变单步质量分类器。
