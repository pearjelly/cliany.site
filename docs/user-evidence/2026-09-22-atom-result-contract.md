# 浏览器子命令结果协议

日期：2026-09-22。状态：Unreleased，公开版本仍为 v0.16.356。

生成适配器通过 run_atom 调用浏览器命令。旧代码解析 stdout 与 stderr 的混合内容，也没有校验退出码、结果对象类型和 ok 状态类型。

七个真实 Click 调用用例在修复前全部失败：带诊断日志的成功与失败信封、成功 JSON 加非零退出码、数组、null、字符串 ok、数字 ok。修复后这七项及已有浏览器上下文相关用例共 17 项通过。

修复只解析 stdout，要求结果是包含布尔 ok 的对象。非零退出码不得返回成功；无效结果统一返回 E_UNKNOWN。合法业务失败仍保留原错误码，因此诊断日志不会把 E_EMPTY_RESULT 改写为解析错误。

未修改生成的适配器文件。此证据证明子命令输出协议，不代表新增公网案例或 LLM 探索成功；并发调用隔离仍是后续工作。
