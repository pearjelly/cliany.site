# 生成动作的次数与顺序

日期：2026-09-22。状态：Unreleased，公开版本仍为 v0.16.356。

## 修复前证据

本地真实 Chromium 表单增加独立提交计数器。单次新生成 CLI 调用返回正确名称，但计数器为 2 而不是 1。仅检查最终字段值会漏掉这个重复副作用。

六种生成代码组合测试均失败：单内联组、多个内联动作、复用动作在前/后、内联-复用-内联、复用-内联-复用。这些测试执行实际生成的 Click 命令，在执行边界检查派发列表的次数、顺序和参数替换，不通过字符串快照猜测行为。

## 原因与修复

首个内联组命名为 action_steps，覆盖总列表并追加自身。现在每个内联组使用独立变量。复用动作还会被通用去重忽略其 atom ID 而删掉，因此复用调用不再进入通用动作去重；不假设复用操作幂等。

全量回归同时暴露提取步骤被通用去重删除，原列表自追加恰好掩盖了步骤与结果数量不匹配。提取步骤也改为保留，质量测试明确断言实际派发数量与结果数量一致。

六种组合修复后通过。真实浏览器回归针对 CLI、workflow、串行 batch 和真实探索产物的新 CLI 回放，都检查每次导航后的页面提交计数恰为 1。未声称网络重试或分布式执行具备全局 exactly-once 保证。

## 升级边界

这是生成模板修复，不会自动改写已安装的生成文件。已有适配器须重新生成或安装重新构建的版本；不得手工修改标记为自动生成的文件。此证据不包含公网案例或真实 LLM。

最终本地全量离线回归 2900 项通过；Ruff 通过，Mypy 检查 123 个源文件通过。
