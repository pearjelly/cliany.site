## Correction and checks

Use a separate, bounded whole-document AX check for the scoped read, leaving interaction visibility and existing selectors unchanged. Require one native `main` landmark and one top-level native list outside navigation. Each direct list item must have a non-hidden linked heading; nested collections are neither competing roots nor returned rows. Resolve this recorded identity again on replay, probe the direct rows for settling, and check the live DOM again before reading. A new scoped adapter requires a supporting runtime; existing generated files and packages are not rewritten.

- Native controls cover layout change, an offscreen row, an extra `main`, competing native/ARIA lists, hidden links, nested metadata and absence of a result collection. They preserve refusal when the read identity is missing or ambiguous.
- A separate no-model Chromium comparison waited for the changed public result before invoking strict structured extraction. `serde` and `tokio` each matched all ten ordered names and crate links from the ordinary page. The third, zero-query observation timed out waiting for the ordinary page's expected text; no extraction was attempted for that query. The saved report contains only the two completed comparisons (SHA-256 `ca97f5cdf474aecac7f0c40ca1ffa6c9b138e339830a1d869a637ebbeab7d0ed`). A controlled empty/missing list is refused, not a proven legitimate empty public replay.
- Local checks: 4,014 offline tests, 55 focused semantic tests including native Chromium, Ruff and mypy. No current exact-head remote CI, real-model generation, pinned candidate archive, independent first-use report or release follows from these checks. Require each independently; the original failed cohorts stay failed.
