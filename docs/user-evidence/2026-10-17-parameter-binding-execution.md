## Correction And Native Evidence

The shared codegen binding helper rejects an explicit or default-matched value override whose action does not execute value. Supported type/select bindings retain ownership, semantic identity and substitution behavior. Existing explicit URL placeholders without a value override are not invented or rewritten by this change. It does not infer a query key, URL encoding policy or navigation template from a fixed URL.

Exploration checks declared completion arguments against both recorded and proposed actions before executing or recording the proposed plan. Invalid bindings use the existing one-shot semantic-plan correction shared with ambiguous targets, ungrounded extraction and duplicate collections. Feedback names indices/action kinds without copying URLs/defaults/returned rows, requests actual AX input/select controls and retains the advertised parameter. Deleting that parameter cannot bypass the guard. Persistent invalidity, exhausted shared allowance or the final step fails with `parameter_binding_invalid`; no step/retry budget is increased and no history is deleted. Existing partition-ownership correction remains separate. This does not repair already generated adapters or guarantee every declared option is semantically correct.
