## Confirmed defect and correction

The old readiness loop set a ten-second deadline but awaited `page.evaluate` outside a timeout. A stalled await could exceed the budget; the stable-success branch also ran before checking the deadline. Numeric and boolean coercions could treat invalid probe states as usable. Ten newly written checks failed on the baseline, while external-cancellation propagation passed.

The candidate includes the awaited read-only probe and poll sleeps in the same existing ten-second cooperative timeout, checks the deadline before accepting stable state, and requires a nonnegative integer count plus a boolean loading flag. JSON-encoded valid states remain supported. External cancellation is not translated into a page error. No navigation, action or model retry is introduced; this is not an entire command deadline or a guarantee against a CPU-blocked event loop.

The private boolean helper remains boolean. Legacy atom errors retain `E_PAGE_NOT_READY` and expose fixed `settle_probe_failed`, `settle_probe_invalid`, `settle_probe_timeout` or `list_unsettled` reasons; action replay stores the same category in its extraction error record. New diagnostics omit probe values and exception bodies. Semantic-target resolution uses the corrected shared budget but retains its existing coarser error contract. Successful payloads, empty-result policy, target identity checks, the 100-row cap, pinned archives and generated files are unchanged. This fixes a demonstrated budget defect and enables future diagnosis; it does not claim to have identified or cured every earlier public failure.
